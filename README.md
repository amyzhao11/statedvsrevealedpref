# stated vs revealed preferences
stated vs revealed preferences and agent-based modelling

We attempted to upload the "ABM core data 89 traits 25.RData" and "ABM core data 171 traits 25.RData" files, but they were too large to upload. So we recommend that if you want to run any of the simulations, to run either the "ABM importance data gen.r" or "ABM preference level efficient data gen.r" first in order to generate these core data files (which are the basis of all the core manuscript simulations). 

These data generation files are in the Simulations folder

We have made some minor updates to the "general stats.r" code to include the analyses of the null models.

We have also uploaded the permutation test output results in the analyses folder.
